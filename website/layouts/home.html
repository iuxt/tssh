01 安装 tssh

所有版本 ↗
⌘macOSApple Silicon / Intel↗>_Linuxx86_64 / ARM / 更多↗⊞Windowsx86_64 / ARM / x86↗

在 Releases 中选择对应系统与架构的压缩包，解压后将 tssh（Windows 为 tssh.exe）放入 PATH 目录。

git clone --depth 1 {{ $repo }}.git
cd tssh
go build -o tssh .

需要 Go 1.25 或以上版本。构建完成后，将生成的可执行文件放入 PATH 目录。

02 添加你的第一台主机

运行 tssh 打开登录界面，按 n 新增主机，保存后即可连接。也可以手动编辑 ~/.tssh/config：

Host my-server
  HostName 192.0.2.10
  User deploy
  Port 22
  GroupLabels 生产

将示例地址与用户替换为你的实际信息。已有 SSH 配置可复制到此文件，或通过 tssh -F ~/.ssh/config 显式读取。
